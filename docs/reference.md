# Borba CAD API reference

Generated by `make docs` from the docstrings of the exported symbols; do not edit by hand.

## BORBA-CAD/APP

The application: state, input events, tools, operations, panels and frame
building. It is headless: a window system feeds it events and draws the draw list it builds.

### `*measure-tool-kinds*` (variable)

The tools that measure, which the Measure button opens.

### `*modify-tool-kinds*` (variable)

The tools that change the selection, which the Modify button opens, as opposed to those that draw.

### `+autosave-interval-nanoseconds+` (constant)

How long a drawing with unsaved changes goes without a copy being written.

### `+drag-threshold-pixels+` (constant)

Pointer travel, in pixels, before a press becomes a drag; below it a release is a click.

### `+pick-radius-pixels+` (constant)

How close, in pixels, the pointer must be to an entity to pick it: about 1.6 mm on screen,
enough for a steady hand and small enough not to grab distant entities.

### `+polar-increment-degrees+` (constant)

The angle, in degrees, whose multiples polar holds the next point to.

### `+snap-radius-pixels+` (constant)

How close, in pixels, the pointer must be to an endpoint or center for object snap to grab it.

### `+zoom-step-per-notch+` (constant)

Zoom factor of one mouse-wheel notch.

### `app` (type)

The whole application state.

- `CONFIG`: configuration.
- `TELEMETRY`: observability hub, or NIL.
- `THEME`: colors.
- `DRAWING`: the drawing being edited.
- `HISTORY`: undo and redo stacks.
- `VIEWPORT`: current view.
- `SELECTION`: hash table of selected entity ids.
- `TOOL`: the active tool.
- `DRAW-LIST`: reused every frame.
- `CURSOR`: last pointer position in world coordinates, or NIL.
- `POINTER-X`: last pointer window x.
- `POINTER-Y`: last pointer window y.
- `INTERACTION`: current pointer drag (:pan or a tool-owned drag) or NIL.
- `TRANSLATION`: (dx . dy) move preview in millimetres, or NIL.
- `WINDOW`: world bounds of the window-selection rectangle, or NIL.
- `WINDOW-CROSSING`: true when that rectangle selects what it touches (dragged from right to left), and
NIL when it selects only what it holds (dragged from left to right).
- `SPACE-DOWN`: true while the space bar is held (pan modifier).
- `FILE-PATH`: path of the drawing file, or NIL.
- `SAVED-REVISION`: drawing revision at the last save or load.
- `FOCUS`: id of the field that has the keyboard focus, or NIL.
- `EDIT`: edit state of that field.
- `PROMPT`: the open modal prompt, or NIL.
- `DIALOG`: the open file dialog, or NIL.
- `MENU`: the open drop-down menu, or NIL.
- `WELCOME`: the start screen, or NIL.
- `POLYGON-SIDES`: the number of sides the polygon tool gives the next polygon.
- `GRIP-DRAG`: the grip being dragged, or NIL.
- `CONSOLE`: the console.
- `CONSTRAINT`: :ortho, :polar or NIL, how the next point is held to the last one.
- `COORDINATE-EDIT`: the edit state of a point being typed, or NIL.
- `AUTOSAVE-TIME`: monotonic time of the last look of the autosave, or NIL before the first.
- `AUTOSAVE-REVISION`: the revision of the drawing in the copy written last, or -1.
- `AUTOSAVE-WRITTEN`: true when this session has written a copy that is still in the state directory.
- `IMAGE-CAPTURER`: function of no arguments that returns what the canvas shows as a picture, as three values: the
pixels (bytes, row by row from the top, red, green and blue of each), the width and the height; or NIL when this
window cannot make one.
- `CLIPBOARD-READER`: function of no arguments that returns the text on the system clipboard, or NIL.
- `CLIPBOARD-WRITER`: function of one string that puts it on the system clipboard, or NIL.
- `CLIPBOARD-FALLBACK`: the clipboard text kept here while there is no system clipboard.
- `MESSAGE`: (text . severity) shown in the status bar, or NIL.
- `MESSAGE-TIME`: monotonic time when the message was set, in nanoseconds.
- `OVERLAY-VISIBLE`: whether the performance overlay is shown.
- `LAYER-SCROLL`: first visible layer row.
- `SEEN-CURRENT-LAYER`: the current layer when the layers card was last built, to scroll the card to a
new one.
- `INSPECTOR-SCROLL`: first visible inspector row.
- `FIELD-COMMIT`: function of the typed string run when the focused field is committed.
- `FIELD-ORIGINAL`: the text the focused field started with; an unchanged field commits nothing.
- `WINDOW-WIDTH`: window width in logical pixels.
- `WINDOW-HEIGHT`: window height in logical pixels.
- `DISPLAY-SCALE`: framebuffer pixels per logical pixel.
- `NEEDS-REDRAW`: true when the next frame differs from the last.
- `QUIT-REQUESTED`: true when the application should close.
- `LAST-SCENE-RESULT`: statistics of the last scene build.
- `LAST-ERROR`: the last error condition reported, for tests and diagnostics.

### `autosave-tick` (function)

```lisp
(autosave-tick app &optional (now (monotonic-nanoseconds)))
```

Do what the autosave needs now: write a copy when the drawing has changes that are not saved and a minute has
passed since the last look, and take the copy away once the drawing has no unsaved changes. Cheap enough to be
called on every pass of the window loop.

- `APP`: the application.
- `NOW`: the monotonic time, in nanoseconds.

### `constrain-point` (function)

```lisp

```

Return the point that MODE holds (X, Y) to, as two values: with :ortho, the nearest point of the horizontal or

### `file-dialog` (type)

The dialog where the user chooses a drawing to open or a place and a name to save to.

- `MODE`: :open or :save.
- `CONTINUATION`: function of no arguments run after a successful save, or NIL.
- `PURPOSE`: :drawing for a drawing of the program, :dxf to import or export a DXF file, or :script to run a
script or export one.
- `DIRECTORY`: the folder shown, as a directory pathname.
- `ENTRIES`: every entry of that folder, folders first, each group by name.
- `SELECTED`: the name of the selected entry, or NIL.
- `SCROLL`: how many visible entries are scrolled past.
- `CAPACITY`: how many rows of the list fit, known once the dialog has been drawn.
- `SHOW-ALL`: true to list every file, false to list only drawings.
- `FILTER-EDIT`: edit state of the search field.
- `NAME-EDIT`: edit state of the file name field.
- `LOCATION-EDIT`: edit state while the path is being typed, or NIL when it is shown as a trail.
- `FOCUS`: which field has the keyboard: :name, :filter or :location.
- `MESSAGE`: a sentence under the list, or NIL.
- `MESSAGE-SEVERITY`: :info or :error.
- `PLACES`: the shortcuts on the side, as (label icon pathname).
- `RECENT`: the recently used drawings, as pathnames, latest first.
- `LAST-CLICK`: the row last clicked and when, to recognize a double click.
- `VISIBLE-CACHE`: the entries the list showed last time with what they were computed from, so that
a folder of tens of thousands of files is not filtered again for every widget of every frame.

## BORBA-CAD/BASE

Units, tolerances, conditions and configuration shared by every module.

### `+angle-tolerance+` (constant)

Angles that differ by no more than this, in radians, count as equal. An arc must sweep more than
this and less than a whole turn by more than this; at the largest radius an arc of this sweep is
0.01 mm long, so no arc a drafter means is ever read as degenerate.

### `+default-frame-summary-interval-seconds+` (constant)

Seconds between aggregated frame/input summary log entries.

### `+default-log-max-bytes+` (constant)

Default size at which a log file is rotated: 5 MiB keeps hours of info-level output.

### `+default-log-max-files+` (constant)

Default number of log files kept (current plus rotated); with 5 MiB each, disk use is
bounded at 25 MiB.

### `+default-memory-sample-interval-seconds+` (constant)

Seconds between memory.sample log entries.

### `+default-window-height+` (constant)

Default window height in logical pixels.

### `+default-window-width+` (constant)

Default window width in logical pixels.

### `+drawing-resolution+` (constant)

Smallest difference a drafter can mean, in millimetres (1 micrometre). It is also the
finest zoom level: one screen pixel per resolution step.

### `+length-tolerance+` (constant)

Lengths at or below this value, in millimetres (1 nanometre), count as zero.
It is 500 times larger than the worst-case representation error at the maximum magnitude
(1.9e-9 mm), so rounding noise never makes a valid segment degenerate, and 1000 times smaller
than +DRAWING-RESOLUTION+, so no intentional feature is ever treated as degenerate.

### `+maximum-coordinate-magnitude+` (constant)

Largest absolute coordinate value accepted, in millimetres (10 km).
Site plans fit comfortably inside it. A double has 53 significant bits, so the spacing
between adjacent doubles at this magnitude is 2^-29 mm (about 1.9e-9 mm), which is the
worst-case representation error of any stored coordinate.

### `+maximum-length+` (constant)

Largest length accepted for any single length value, in millimetres. The diagonal of the
square of valid coordinates is 2.83e7 mm, so every distance between two valid points fits;
the bound also keeps every product and sum computed from lengths far from overflow.

### `borba-cad-error` (condition)

Root of every error that Borba CAD signals deliberately. Its report is a
complete, user-facing message in the language of the interface.

## BORBA-CAD/PERSISTENCE

The .bcad drawing format: a small safe S-expression reader, a writer whose
numbers round-trip exactly, strict validation, and atomic saving.

### `*drawing-extension*` (variable)

Extension that a drawing file name gets when it does not already end in one that the program
writes.

### `*known-drawing-extensions*` (variable)

Extensions of the file formats that the program writes. A name that ends in one of them is
saved as typed; any other name, including one with a different extension such as plan.txt or
v1.2 final, gets .bcad after it.

### `+maximum-file-bytes+` (constant)

Largest drawing file that will be read. A 100,000-entity drawing is about 12 MB; the limit
bounds the memory used to read an untrusted file (NFR-7).

### `+maximum-nesting-depth+` (constant)

Deepest list nesting accepted. The format needs 4; the limit protects the stack.

### `+maximum-token-length+` (constant)

Longest word or number accepted, in characters. Doubles print in at most 24.

### `+oldest-supported-format-version+` (constant)

The oldest format version this program still reads, migrating it as it is read.

### `+recent-file-limit+` (constant)

Most drawings the recent list remembers.

### `+supported-format-version+` (constant)

The newest format version: the one this program writes, and the newest it reads.

## BORBA-CAD/SCRIPT

The language the program can be driven with: commands that draw and edit, written in Lisp
and run against a drawing; the context they run in, with the transaction that makes each command a single step
of undo; the evaluator, which reads, runs and reports; and the writer that turns a drawing back into the
commands that draw it.

### `*context*` (variable)

The context of the command that is running.

### `*maximum-changes*` (variable)

Most entities a single command may create, change or erase: well beyond what a drawing is meant to hold,
and a bound on the memory a runaway loop can ask for.

### `+default-timeout-seconds+` (constant)

Longest time a command typed in the console may run.

### `+script-timeout-seconds+` (constant)

Longest time a script file may run.

### `arc` (function)

```lisp

Read the forms in TEXT and run them one after the other against the drawing of CONTEXT, as a single

- `TIMEOUT`: the longest time to run, in seconds.

### `script-context` (type)

What a command runs against.

- `DRAWING`: the drawing it draws on.

## BORBA-CAD/VIEWPORT

The only place where world coordinates (millimetres, +y up) meet screen
coordinates (logical pixels, +y down). Zoom, pan, fitting and the adaptive grid.

### `+default-visible-width+` (constant)

World width in millimetres shown by the default viewport (20 m).

### `+fit-margin-pixels+` (constant)

Empty border left around the content by FIT-VIEWPORT-TO-BOUNDS.

### `+grid-major-interval+` (constant)

Every this many displayed grid lines, one is drawn as a major line.

### `+maximum-grid-lines-per-axis+` (constant)

Safety bound on the lines drawn per axis; reachable only with a degenerate viewport.

### `+maximum-scale+` (constant)

Largest zoom, in pixels per millimetre: one pixel is 1 micrometre, the drawing resolution.

### `+minimum-grid-spacing-pixels+` (constant)

Closest the displayed grid lines may be, in pixels. Below it a grid reads as noise.

### `+minimum-scale+` (constant)

Smallest zoom, in pixels per millimetre: one pixel is 10 m, so the whole coordinate range
(20 km across) fits in about 2000 pixels.

### `clamp-scale` (function)

```

Return SCALE limited to the allowed zoom range.

- `SCALE`: pixels per millimetre.

### `compute-grid-level` (function)

keeps the lines at least +MINIMUM-GRID-SPACING-PIXELS+ apart.

- `VIEWPORT`: the viewport.
